Airline Route & Merger Analysis

Analyzed US Department of Transportation flight data across 10,000+ domestic routes to evaluate the competitive impact of the proposed JetBlue and Spirit Airlines merger.

What I Did

  • Used PostgreSQL window functions to calculate carrier market shares by origin and destination airport pairs.
  • Calculated route market concentration (Herfindahl-Hirschman Index / HHI) before and after the proposed merger to see which specific routes would see the biggest drop in airline competition.
  • Identified routes that exceeded regulatory thresholds, showing where passenger airfares were most vulnerable to price increases.

-- Airline Route Market Share & HHI Analysis
WITH RoutePassengers AS (
    SELECT 
        origin, dest, carrier,
        SUM(passengers) AS carrier_passengers,
        SUM(SUM(passengers)) OVER (PARTITION BY origin, dest) AS total_route_passengers
    FROM us_dot_db1b_flights
    GROUP BY origin, dest, carrier
),
CarrierMarketShare AS (
    SELECT 
        origin, dest, carrier,
        ROUND((carrier_passengers::numeric / total_route_passengers) * 100, 2) AS market_share_pct
    FROM RoutePassengers
),
PrePostMergerHHI AS (
    SELECT 
        origin, dest,
        ROUND(SUM(POWER(market_share_pct, 2)), 0) AS pre_hhi,
        ROUND(SUM(POWER(
            CASE WHEN carrier IN ('B6', 'NK') THEN 
                SUM(CASE WHEN carrier IN ('B6', 'NK') THEN market_share_pct ELSE 0 END) OVER (PARTITION BY origin, dest)
            ELSE market_share_pct END, 2)), 0) AS post_hhi
    FROM CarrierMarketShare
    GROUP BY origin, dest
)
SELECT origin, dest, pre_hhi, post_hhi, (post_hhi - pre_hhi) AS delta_hhi
FROM PrePostMergerHHI
WHERE post_hhi > 2500 AND (post_hhi - pre_hhi) >= 200
ORDER BY delta_hhi DESC;

BYU STRATEGY 402 • Econometrics

Airbnb Pricing & Demand Modeling

Analyzed a large multi-city dataset of Airbnb listings in R to study how nightly pricing impacts booking demand and host revenue.

What I Did

  • Cleaned and prepared listing data in R, controlling for factors like property size, bedrooms, superhost status, and review scores.
  • Ran multivariate regressions with neighborhood fixed effects to isolate the true relationship between price and estimated bookings.
  • Found that demand in major markets was slightly elastic (a 10% price increase led to roughly a 10.5% drop in bookings), showing the trade-offs hosts make between occupancy and revenue.

# Airbnb Demand Regression in R
library(tidyverse)
library(fixest)

# Clean and filter listing data
airbnb_data <- read_csv("airbnb_multicity.csv") %>%
  filter(price > 15 & price < 2500, estimated_bookings_30d > 0) %>%
  mutate(log_bookings = log(estimated_bookings_30d), log_price = log(price))

# Multivariate regression with neighborhood fixed effects
model <- feols(
  log_bookings ~ log_price + accommodates + bedrooms + review_scores_rating | 
                 metro_market^neighbourhood_cleansed,
  data = airbnb_data,
  vcov = "cluster" ~ neighbourhood_cleansed
)

summary(model)
BYU STRATEGY 412 • Geospatial Analysis

Grocery Store Expansion Analysis

Built a data pipeline to identify high-potential expansion zip codes for Sprouts Farmers Market by combining store locations with US Census demographic data.

What I Did

  • Scraped location coordinates for existing grocery competitors (Sprouts, Whole Foods, Trader Joe's).
  • Pulled demographic data (median household income, population) from the US Census Bureau API by zip code.
  • Calculated competitor proximity within a 3-mile trade radius around candidate areas and visualized the ranked results in Tableau.

# Store Location & Census Pipeline
import requests, pandas as pd
from geopy.distance import geodesic

CENSUS_API_URL = "https://api.census.gov/data/2022/acs/acs5"

def score_locations(candidate_zips, competitors, census_df):
    results = []
    for _, zip_row in candidate_zips.iterrows():
        coord = (zip_row["lat"], zip_row["lon"])
        
        # Count competitors within 3 miles
        competitor_count = sum(
            geodesic(coord, (c["lat"], c["lon"])).miles <= 3.0 
            for _, c in competitors.iterrows()
        )
        
        income = census_df.loc[census_df["zip"] == zip_row["zip_code"]]["median_income"].values[0]
        results.append({**zip_row, "competitors_3mi": competitor_count, "income": income})
        
    return pd.DataFrame(results)
